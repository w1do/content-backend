# ГазТочка — SUMMARY

## Текущий статус
Проект находится в активной фазе разработки. Реализован базовый функционал каталога товаров, CMS и иерархии категорий.

## Последние изменения
- **[Products]** Расширение возможностей фильтрации товаров.
    - Реализована фильтрация товаров по слагу (`slug`) в API.
    - Добавлена поддержка фильтрации по списку слагов.
    - Обновлена Swagger-документация и DTO фильтров.
- **[SEO]** Интеграция SEO и динамических промптов.
    - Реализована система управления промптами для AI-генерации через базу данных.
    - Добавлена поддержка категорий промптов: General, Category, Products, Posts, Page.
    - Реализована логика объединения общего контекста проекта (General) с правилами конкретных разделов.
    - Добавлена поддержка передачи контекста сущности (название, описание) в AI для повышения точности генерации.
    - Интегрирована панель управления промптами в Filament (`PromptResource`).
    - Реализовано действие "Улучшить prompt" в Filament, использующее ИИ для оптимизации Markdown-текста правил.
    - Реализована массовая генерация SEO (Bulk Actions) для категорий и товаров в Filament.
    - Внедрена фоновая обработка через `GenerateSeoJob` для масштабируемости.
    - Добавлен фильтр в Bulk Action, исключающий перезапись уже заполненных SEO-данных.
    - Добавлена поддержка автоматической генерации с помощью AI через `SeoGenerator`.
    - Обновлена документация системы SEO и промптов.
- **[UI/UX]** Рефакторинг формы товара в Filament (`ProductResource`).
    - Внедрены вкладки: Главное, Медиа, Сео, Подгрузка товара.
    - Использован гибкий Split-layout (Flex) для выноса категорий в боковую панель.
    - Страницы ресурса переведены в режим Full Width.
    - Оптимизировано распределение пространства на странице редактирования.

## Основные модули
- **Каталог**: Иерархические категории, товары с динамическими атрибутами.
- **CMS**: Блог, страницы, системные тексты.
- **Инфраструктура**: Redis-кеширование (Decorator), Media Library, DDD/CQRS архитектура.
