# ГазТочка — SUMMARY

## Текущий статус
Проект находится в активной фазе разработки. Реализован базовый функционал каталога товаров, CMS и иерархии категорий.

## Последние изменения
- **[Products]** Расширение возможностей фильтрации товаров.
    - Реализована фильтрация товаров по слагу (`slug`) в API.
    - Добавлена поддержка фильтрации по списку слагов.
    - Обновлена Swagger-документация и DTO фильтров.
- **[SEO]** Интеграция SEO в API и ядро проекта.
    - Добавлена поддержка SEO в доменные сущности `Category` и `Product`.
    - Реализован `SeoResource` для API с поддержкой OpenAPI/Swagger.
    - Добавлена автоматическая подгрузка и маппинг SEO в репозиториях категорий и товаров.
    - В списки категорий и товаров в Filament добавлена колонка для мониторинга SEO.
- **[UI/UX]** Рефакторинг формы товара в Filament (`ProductResource`).
    - Внедрены вкладки: Главное, Медиа, Сео, Подгрузка товара.
    - Использован гибкий Split-layout (Flex) для выноса категорий в боковую панель.
    - Страницы ресурса переведены в режим Full Width.
    - Оптимизировано распределение пространства на странице редактирования.

## Основные модули
- **Каталог**: Иерархические категории, товары с динамическими атрибутами.
- **CMS**: Блог, страницы, системные тексты.
- **Инфраструктура**: Redis-кеширование (Decorator), Media Library, DDD/CQRS архитектура.
