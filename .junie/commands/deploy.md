Используй эту команду для подготовки проекта к деплою. Она активирует навык деплоя и предоставляет пошаговый план действий.

### 📚 Инструкции и навыки (Skills)
Перед началом обязательно изучи навык деплоя:
- **Laravel Deploy**: `.agents/skills/laravel-deploy`

### 🚀 Порядок действий для деплоя

1. **Проверка окружения**:
   - Убедись, что файл `.env` настроен для продакшена (`APP_ENV=production`, `APP_DEBUG=false`).
   - Проверь наличие всех необходимых секретов.

2. **Локальная проверка сборки**:
   - Запусти сборку Docker-образа, чтобы убедиться в отсутствии ошибок в `Dockerfile`.
   - Команда: `docker build -t laravel-app-prod .`

3. **Оптимизация (через Sail, если доступно)**:
   - Если нужно проверить кэширование локально:
     - `./vendor/bin/sail artisan config:cache`
     - `./vendor/bin/sail artisan route:cache`
     - `./vendor/bin/sail artisan view:cache`

4. **Миграции**:
   - При деплое миграции должны выполняться автоматически через `entrypoint.sh`. 
   - Убедись, что БД доступна и пользователь имеет права на выполнение миграций.

### 🏗 Пример Dockerfile (текущий проект)
Проект использует мультистадийную сборку на базе PHP 8.5 и Node 22.

- **Stage 1 (Composer)**: Устанавливает зависимости.
- **Stage 2 (Node)**: Собирает фронтенд (Vite + Tailwind 4).
- **Stage 3 (Final)**: Объединяет PHP, Nginx и Supervisord.

### 🛠 Полезные команды

- **Сборка**: `docker build -t app-name .`
- **Запуск**: `docker run -p 80:80 --env-file .env app-name`
- **Логи**: `docker logs -f [container_id]`

### ✅ Чеклист перед сабмитом изменений в Docker/Deploy:
- [ ] `Dockerfile` успешно собирается.
- [ ] `entrypoint.sh` имеет права на выполнение (`chmod +x`).
- [ ] Все PHP расширения (bcmath, gd, intl, pdo_pgsql, zip, pcntl, redis) установлены.
- [ ] Кэширование Laravel включено в процессе деплоя.
