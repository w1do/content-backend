Используй эту команду для приведения существующего кода к целевой архитектуре проекта. Рефакторинг должен выполняться поэтапно с обязательным сохранением работоспособности и написанием тестов.

### 🛠 Как использовать
Для выполнения этой команды ты **должен** активировать и следовать инструкциям из навыка:
👉 **Skill**: `refactoring-ddd` (находится в `.ai/skills/refactoring-ddd`)

### 📋 Чек-лист рефакторинга
1. [ ] Изучи текущую реализацию и напиши тесты (если их нет).
2. [ ] Опиши DTO для входных данных.
3. [ ] Вынеси логику в Command/Handler (для Write) или Query (для Read).
4. [ ] Упрости контроллер до вызова Handler/Query.
5. [ ] Добавь Swagger-аннотации.
6. [ ] Выполни проверку качества:
    - `./vendor/bin/sail pint --dirty`
    - `./vendor/bin/sail phpstan analyse`
7. [ ] Убедись, что все тесты проходят: `./vendor/bin/sail test --compact`.

Подробные примеры кода и архитектурные правила ищи в документации навыка `refactoring-ddd`.
