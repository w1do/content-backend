# Документация Категорий

## Обзор
Система категорий позволяет организовывать товары в иерархическую структуру (Nested Set). Это обеспечивает эффективный поиск товаров по дереву категорий и генерацию хлебных крошек.

## Структура и Иерархия
Категории поддерживают неограниченную вложенность. Для управления деревом используется пакет `kalnoy/nestedset`.

Пример иерархии:
- **Оборудование** (root)
  - **Газовое оборудование** (child)
    - **Баллоны** (grandchild)

## API Эндпоинты

### CRUD Операции
- `GET /api/v1/categories` - Список всех категорий. Теперь возвращает непосредственных детей (первый уровень) в поле `children`.
- `GET /api/v1/categories/tree` - Получение дерева категорий (рекурсивная структура).
- `GET /api/v1/categories/{id}` - Детальная информация о категории. Включает детей в поле `children`.
- `POST /api/v1/categories` - Создание новой категории.
  - Поля: `name`, `slug`, `parent_id` (опционально), `description`, `status` (active/inactive).
- `PUT /api/v1/categories/{id}` - Обновление категории.
- `DELETE /api/v1/categories/{id}` - Удаление категории. **Внимание:** удаление родительской категории влечет за собой удаление всех дочерних категорий.

### Навигация и Товары
- `GET /api/v1/categories/{id}/breadcrumbs` - Получение хлебных крошек. Возвращает массив родительских категорий от корня до текущей.
- `GET /api/v1/categories/{id}/products` - Получение товаров категории.
  - Параметр `include_children` (по умолчанию `true`): если включен, возвращает товары текущей категории и всех её подкатегорий.

## Фильтрация
Эндпоинт `GET /api/v1/categories` поддерживает гибкую фильтрацию через параметры запроса `filter[...]` с использованием пакета `spatie/laravel-query-builder`.

### Доступные фильтры:
- `filter[id]` — поиск по ID категории. Поддерживает множественные значения через запятую (например, `?filter[id]=1,2,5`).
- `filter[name]` — частичный поиск по названию категории (LIKE %value%).
- `filter[slug]` — точный поиск по слагу категории.
- `filter[full_path]` — точный поиск по полному пути.

Фильтры реализованы через отдельные классы в `App\Infrastructure\Persistence\Eloquent\Filters\Categories\`.

## Полный путь категории (full_path)
Каждая категория хранит поле `full_path` — полный путь по иерархии в виде слагов, разделённых `/` (например, `oborudovanie/gazovoe-oborudovanie/ballony`). Путь используется для построения навигации по дереву категорий и напрямую отображается в `CategoryResource` и `ProductResource`.

- **Генерация**: метод `Category::generateFullPath()` собирает слаги всех предков (`ancestors()`) и добавляет собственный слаг категории.
- **Автоматическое обновление**: модель `App\Infrastructure\Persistence\Eloquent\Category` содержит хуки `creating`/`updating`, которые пересчитывают `full_path` при создании и изменении категории, и хук `saved`, который каскадно обновляет `full_path` у всех потомков, если путь текущей категории изменился (переименование или перемещение в другого родителя).
- **Дерево категорий**: при построении дерева (`GET /api/v1/categories/tree`) каждая категория в ответе содержит `full_path` и рекурсивно вложенные `children` с их собственными `full_path`, что позволяет сразу переходить по нужному пути и показывать товары без дополнительных запросов.
- **Обратная совместимость**: команда `php artisan categories:generate-full-paths` пересчитывает и сохраняет `full_path` для всех существующих категорий (используется один раз при внедрении функциональности).

## Архитектурные решения
- **DDD**: Логика работы с категориями инкапсулирована в доменном слое (`App\Domain\Entities\Category`).
- **CQRS**: Все операции разделены на команды (изменение состояния) и запросы (чтение).
- **Nested Set**: Позволяет получать все товары из поддерева одним SQL-запросом через `whereHas` и `whereIn`.

## Тестирование
Функциональность покрыта тестами:
- `tests/Feature/CategoryTest.php` - базовые операции и Nested Set.
- `tests/Feature/Api/V1/CategoryFilteringTest.php` - фильтрация по ID, названию, слагу и пути.

Тесты проверяют:
- Создание, обновление и удаление категорий.
- Правильность построения дерева.
- Корректность генерации хлебных крошек.
- Фильтрацию товаров по иерархии категорий.
- Генерацию `full_path` для новой, вложенной, перемещённой и переименованной категории.
- Наличие `full_path` и вложенных `children` в ответе дерева категорий.
- Фильтрацию списка категорий по всем доступным полям.
