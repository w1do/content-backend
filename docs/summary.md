# Краткое описание реализованных изменений

## Категории и Иерархия товаров
- **CRUD**: Реализован полный цикл операций для категорий (создание, чтение, обновление, удаление).
- **Вложенные дети**: Обеспечена автоматическая загрузка подкатегорий первого уровня (`children`) во всех методах чтения репозитория, что позволяет отображать структуру подразделов при поиске и просмотре категорий.
- **Фильтрация**: Реализована гибкая фильтрация через `spatie/laravel-query-builder` с использованием кастомных классов фильтров для поиска по `id`, `name`, `slug` и `full_path`.
- **Nested Set**: Использование иерархической структуры для категорий (пакет `kalnoy/nestedset`), позволяющее строить вложенность любого уровня.
- **Хлебные крошки**: Эндпоинт для получения цепочки родительских категорий.
- **full_path**: Автоматическая генерация полного пути категории (слаги предков + собственный слаг) с каскадным обновлением потомков при перемещении/переименовании; путь доступен в дереве категорий (`CategoryResource`) и в товарах (`ProductResource.category_full_path`).

## Товары (Products)
- **Каталог**: Реализован вывод списка товаров и детальной информации.
- **Связь с категориями**: Возможность получения товаров из всей ветки категорий (включая дочерние).
- **Гибкость**: Использование JSON-поля для динамических атрибутов товара.
- **Медиа**: Поддержка обложек товаров (`cover_url`) с автоматической обрезкой и fallback-ом на основное изображение.

## Медиа-система (Media Library)
- **Cover изображения**: Реализован вывод `cover_url` для товаров и категорий через `spatie/laravel-medialibrary`.
- **Конверсии**: Автоматическое создание обложек размером 800x600 (`Fit::Crop`) для оптимизации производительности фронтенда.
- **Fallback логика**: При отсутствии специальной обложки система автоматически использует основное изображение (`main`) с применением конверсии.

## Контентная система (CMS)
- **Многофункциональность**: Поддержка различных типов контента (Блог, Страницы, Системные тексты).
- **API**: Отдельные эндпоинты для каждого типа контента.
- **Управление**: Полноценная админка на Filament для редактирования текстов.

## Архитектура и Качество кода
- **Кеширование (Caching)**: Прозрачная прослойка кеширования (Redis) для категорий и товаров с использованием паттерна Декоратор и автоматической инвалидацией через Observers.
- **DDD & CQRS**: Четкое разделение на слои (Domain, Application, Infrastructure, Presentation). Использование команд/запросов и хендлеров.
- **Filament PHP**: Современная админ-панель для управления всеми сущностями проекта.
- **Тестирование**: Высокое покрытие тестами (Pest) для API и админки.
- **API Documentation**: Интеграция Swagger (L5-Swagger / OpenApi) для автодокументирования эндпоинтов.
