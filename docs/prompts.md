# Управление промптами SEO (Prompts)

## Обзор
Система управления промптами позволяет администраторам настраивать правила генерации SEO-данных (Title и Description) через панель управления Filament. Это исключает необходимость вносить изменения в код для корректировки "личности" AI или специфических правил для разных типов контента.

## Структура
- **Модель**: `App\Infrastructure\Persistence\Eloquent\Prompt`
- **Репозиторий**: `App\Domain\Repositories\PromptRepositoryInterface` (Реализация: `EloquentPromptRepository`)
- **Сервис**: `App\Application\Services\PromptService`
- **Энум категорий**: `App\Domain\Enums\PromptCategory` (General, Category, Products, Posts, Page)

## Логика объединения правил и контекст
При генерации SEO для конкретного типа контента система формирует запрос к AI следующим образом:
1. **Контекст сущности**: В запрос передается название (Title) сущности и основной контент/описание. Это позволяет AI лучше понимать, о чем именно идет речь.
2. **Общие правила**: Берется активный промпт категории `General`. Он задает "личность" AI и общий контекст бренда.
3. **Специфические правила**: Берется активный промпт для конкретной категории (например, `Products`).
4. **Технические правила**: Добавляются инструкции по формату (JSON), ограничениям по длине и языку.

Результат передается AI как единый список инструкций.

## Управление
Управление промптами осуществляется в разделе "Промпты" админ-панели.
- **Категория**: Уникальный идентификатор типа контента.
- **Правило**: Текст инструкции в формате Markdown.
- **Статус**: Позволяет временно отключать правило.
- **Улучшение промпта**: В таблице промптов доступно действие "Улучшить prompt" (иконка искр). Система использует ИИ (через `PolzaAiService`) для анализа текущего Markdown и предлагает улучшенную версию правила, делая его более четким и структурированным.

## Технические детали
- Если в базе данных нет активных промптов, система использует набор встроенных правил по умолчанию.
- Технические правила (JSON формат) добавляются всегда в конец списка, чтобы гарантировать корректный парсинг ответа от AI.
