# MixedContentGenerate — Генерация уникального описания товара

## Описание
`MixedContentGenerate` — это переиспользуемая утилита в слое Domain, предназначенная для автоматического создания уникального описания товара в формате Markdown при его импорте по ссылке.

Инструмент использует комбинацию данных, полученных парсером, и искусственного интеллекта (Polza AI) для формирования качественного, структурированного и уникального контента, соответствующего общей стилистике проекта.

## Основные возможности
- **Автоматическая трансформация**: Мгновенное преобразование сырых данных парсинга в Markdown.
- **Интеллектуальный синтез**: Если исходное описание отсутствует, ИИ генерирует текст на основе названия и технических характеристик товара.
- **Контекстная уникализация**: Использует `General` промпт из базы данных для подмешивания "сути проекта" (правил, тональности, ключевых слов) в каждое описание.
- **Отказоустойчивость**: Если сервис ИИ недоступен, сохраняется оригинальное описание, полученное парсером.

## Техническая реализация
- **Класс**: `App\Domain\Features\MixedContentGenerate`
- **Интеграция**: Внедрен в `App\Application\Handlers\Products\ParseProductFromUrlHandler`.
- **Зависимости**:
    - `PromptRepositoryInterface` — для получения правил проекта.
    - `PolzaAiService` — для взаимодействия с LLM.

## Процесс работы
1. `ParseProductFromUrlHandler` инициирует парсинг товара.
2. Полученный `ParsedProductDTO` передается в `MixedContentGenerate`.
3. Утилита собирает:
    - Название товара.
    - Исходное описание (если есть).
    - Список характеристик (атрибутов).
    - Общий промпт проекта (`PromptCategory::General`).
4. Формируется запрос к ИИ для создания уникального Markdown-текста.
5. Результат записывается обратно в `ParsedProductDTO->description`.

## Тестирование
Функционал покрыт тестами в `tests/Feature/MixedContentGenerateTest.php`, проверяющими:
- Успешную генерацию Markdown при наличии всех данных.
- Генерацию на основе только характеристик (при пустом описании).
- Корректную работу при сбое сервиса ИИ.
