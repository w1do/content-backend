# Поиск и подбор изображений (SerpApi)

## Обзор
Функционал позволяет контент-менеджерам быстро находить и прикреплять изображения к товарам и категориям непосредственно из панели управления Filament, используя поисковую выдачу Google Images через SerpApi.

## Архитектура

### Компоненты
- **Провайдер**: `SerpApiImageSearchProvider` — выполняет запросы к SerpApi и возвращает список результатов.
- **DTO**: `ImageSearchResult` — содержит URL, заголовок и источник изображения.
- **Экшен**: `SearchImageAction` — кастомное действие Filament, интегрируемое в формы.
- **Хендлер**: `AttachImageFromUrlHandler` — отвечает за физическую загрузку изображения и его регистрацию в MediaLibrary.

### Схема работы
1. Пользователь нажимает на иконку поиска (лупа) рядом с полем «Наименование».
2. Система выполняет поиск в SerpApi по текущему значению поля.
3. Открывается модальное окно с сеткой из 12 найденных изображений.
4. При клике на изображение оно подсвечивается (выбор сохраняется в скрытое поле формы экшена).
5. При нажатии «Сохранить»:
    - Изображение скачивается по URL во временный файл (`Http::get`, таймаут 30с).
    - Изображение нормализуется до единого размера **800x800** (`Fit::Crop`, обрезка по центру) и конвертируется в JPEG (качество 90).
    - Файлу присваивается имя на основе слага сущности с расширением `.jpg` (например, `gazovyi-kotel-bosch.jpg`).
    - Коллекция `main` очищается перед привязкой (`clearCollection: true`).
    - Изображение добавляется в коллекцию `main`, временный файл удаляется.
    - Вызывается `refreshFormData(['image'])`, чтобы поле «Главное изображение» сразу показало новую картинку.

### Нормализация размера
- Размер задаётся параметрами `width` / `height` команды `AttachImageFromUrlCommand` (по умолчанию `800x800`).
- Используется `Fit::Crop`: изображение масштабируется и обрезается по центру, поэтому итоговый файл всегда строго квадратный без искажений пропорций.
- Все изображения сохраняются в формате JPEG независимо от исходного формата.

## UI / UX особенности
- **Сетка**: адаптивная (`auto-fill`, минимальная ширина карточки 150px).
- **Стили**: компонент `image-picker` использует инлайн-стили, так как кастомные Tailwind-классы не попадают в скомпилированный CSS панели Filament (без своей темы).
- **Предпросмотр**: карточки строго квадратные (`aspect-ratio: 1/1`) с `object-fit: cover`.
- **Индикация**: выбранная карточка получает оранжевую рамку и компактную галочку в правом верхнем углу.
- **Состояние**: выбор пишется в состояние формы экшена через `$wire.set()` (отложенно), что исключает конфликты `$entangle` с вложенным путём `mountedActions.*.data`.
- **Валидация**: Кнопка сохранения не сработает, пока не выбрано хотя бы одно изображение.

## Настройка
Для работы необходимо наличие ключа `SERP_API` в файле `.env`.
Если ключ отсутствует, экшен уведомит пользователя об ошибке конфигурации.
