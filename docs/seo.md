# Система SEO (Поисковая оптимизация)

## Обзор
Система SEO в GazTochka реализована как полиморфная связь, позволяющая прикреплять мета-данные для поисковых систем к любой сущности проекта (Категории, Товары, Контент).

## Структура данных
Данные SEO хранятся в отдельной таблице `seos` и включают следующие поля:
- `title`: Заголовок страницы (Title).
- `description`: Описание страницы (Description).
- `is_indexable`: Флаг, разрешающий индексацию поисковыми роботами.
- `image`: Изображение для социальных сетей (OpenGraph).
- `meta`: Дополнительные JSON мета-теги.

## Реализация

### Domain Layer
- **Сущность `Seo`**: Содержит бизнес-логику и структуру данных SEO.
- **Интерфейс `SeoRepositoryInterface`**: Определяет методы для работы с SEO данными.
- **Трейт `HasSeo`**: Подключается к Eloquent моделям для обеспечения связи `morphOne`.

### Infrastructure Layer
- **Eloquent модель `Seo`**: Работает с Media Library для хранения изображений.
- **Репозитории**: `EloquentCategoryRepository` и `EloquentProductRepository` автоматически подгружают и мапят SEO данные в доменные сущности при запросах.

### Presentation Layer (API)
- **`SeoResource`**: Трансформирует доменную сущность SEO в формат JSON для API.
- **Интеграция**: Поле `seo` добавлено в `CategoryResource` и `ProductResource`.
- **Swagger**: Добавлены аннотации OpenAPI для всех SEO полей.

### Административная панель (Filament)
- **`SeoSchema`**: Общий компонент для подключения полей SEO в любые формы.
- **Таблицы**: В списки категорий и товаров добавлена колонка "SEO Title" для быстрого контроля заполненности данных.
- **Массовые действия (Bulk Actions)**: Добавлена кнопка "Сгенерировать SEO" в список категорий и товаров. Позволяет массово отправлять записи на генерацию в фоновом режиме.

## AI Генерация SEO
Для автоматизации заполнения SEO-данных используется `PolzaAiService` и `SeoGenerator`.

### Процесс генерации:
1. Система извлекает текст для анализа (описание сущности или её название).
2. Формируется запрос к ИИ (GPT-4o-mini) с инструкциями по созданию оптимизированного Title и Description.
3. Полученные данные сохраняются в БД, если поля SEO были пусты.

### Массовая обработка:
Массовая генерация реализована через `SeoGenerateBulkAction` и очередь задач Laravel:
- Фильтрует записи, у которых SEO уже заполнено.
- Для каждой нуждающейся записи ставит в очередь задачу `GenerateSeoJob`.
- Информирует администратора о количестве запущенных задач через Notification.

## Использование в API
При запросе категории или товара через API, данные SEO возвращаются в объекте `seo`:

```json
{
  "data": {
    "id": 1,
    "name": "Название",
    "seo": {
      "title": "SEO Заголовок",
      "description": "SEO Описание",
      "is_indexable": true,
      "image_url": "http://...",
      "meta": {}
    }
  }
}
```
