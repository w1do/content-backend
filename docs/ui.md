# UI Документация

## Архитектура
В проекте используется методология FSD (Feature-Sliced Design).

## Компоненты данных (API Data)

### Product / Category Cover
Для отображения обложек товаров и категорий необходимо использовать поле `cover_url`, предоставляемое API.

- **Размер**: 800x600 пикселей.
- **Обработка**: Изображение обрезается (Fit::Crop) на стороне сервера для обеспечения единообразия сетки.
- **Применение**: Карточки товаров, баннеры категорий.

## UI Компоненты (React)
*На данный момент UI компоненты находятся в процессе разработки или переносятся на FSD.*

## SEO Компоненты (Filament)

### SeoSchema
Унифицированная секция для управления SEO-данными. Включает в себя поля:
- **SEO Заголовок** (title)
- **SEO Описание** (description)
- **Индексация** (is_indexable)
- **SEO Изображение** (Spatie Media Library)

Используется в `ProductForm`, `CategoryForm`, `ContentForm`.

### SeoGenerateAction
Кнопка-действие (suffix action), вызывающая генерацию SEO-данных через Polza AI на основе содержимого поля (например, описания товара).
Интегрирована в поля описания во всех основных формах.

## Формы (Filament)

### ProductForm
Форма редактирования товара, оптимизированная для удобства контент-менеджеров:
- **Разделение по табам**:
    - *Главное*: Название, слаг, описание (с AI генерацией SEO), характеристики (KeyValue).
    - *Медиа*: Главное изображение и галерея (Spatie Media Library).
    - *Сео*: Интегрированная `SeoSchema`.
    - *Подгрузка товара*: Инструментарий для автоматического парсинга данных товара с mirgaza.ru по ссылке.
- **Split Layout (Flex)**: Использование гибкого разделения пространства: основная информация занимает все доступное место, а выбор категорий вынесен в компактную боковую панель.
- **Full Width**: Страницы ресурса настроены на использование всей ширины экрана (`Width::Full`), что обеспечивает комфортную работу с контентом на широкоформатных мониторах.
